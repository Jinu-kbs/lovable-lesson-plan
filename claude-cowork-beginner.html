1. Claude Cowork란?

한 줄 정의

Claude Cowork는 Anthropic이 2026년 1월 공개한 데스크톱 기반 자율 업무 에이전트(agentic AI for knowledge work)입니다. 내 컴퓨터의 특정 폴더와 "목표(goal)"를 주면, Claude가 로컬 파일과 앱을 직접 읽고·만들고·수정하며 여러 단계의 작업을 스스로 수행해 완성된 산출물(finished deliverable)을 돌려줍니다.

"목표를 주면 Claude가 당신의 컴퓨터·로컬 파일·애플리케이션에서 작업해 완성된 산출물을 돌려준다." — Anthropic 공식 제품 페이지 요약

Claude Code의 비개발자 버전

Anthropic 내부에서는 Cowork를 "코딩 외 나머지 업무를 위한 Claude Code(Claude Code for the rest of your work)"라고 부릅니다. 둘은 같은 기술 기반 위에 서 있지만, 사용 방식이 다릅니다.

인터페이스터미널(CLI) 중심Claude 데스크톱 앱의 탭 (Chat / Cowork)
진입 장벽명령줄·기술 지식 필요코딩·터미널 불필요, 자연어로 위임
샌드박스 설정사용자가 직접 구성자동 구성 (VM 기반 격리)
작업 단위코드베이스·리포지토리로컬 폴더·문서·앱
대표 작업코드 작성·디버깅파일 정리, 문서 초안, 리서치 종합, 데이터 추출

쉽게 말해 Cowork는 데스크톱 위에서 로컬 파일과 앱을 넘나들며 업무를 통째로 수행하는 비서입니다. 채팅으로 답만 주는 일반 챗봇과 달리, Claude가 실제로 폴더를 열고 파일을 만들고 정리합니다.

대표 사용 사례 4가지

Anthropic 공식 페이지가 제시하는 4대 워크플로우입니다.

  1. 파일 정리 — 로컬 파일 이름 변경·분류·중복 제거 (예: 어지러운 다운로드 폴더 정돈)
  2. 문서 준비 — 흩어진 메모로부터 구조화된 첫 초안 작성
  3. 리서치 종합 — 여러 출처에 걸친 발견을 요약
  4. 데이터 추출 — 비정형 문서를 표로 변환 (예: 영수증 스크린샷 → 경비 정산 스프레드시트)

2. 설치하기 (macOS / Windows)

시작 전 준비물

  • 유료 Claude 구독 (Pro / Max / Team / Enterprise 중 하나) — 무료 플랜으로는 사용할 수 없습니다
  • Claude 데스크톱 앱 (macOS 또는 Windows 최신 버전)
  • 작업 중 인터넷 연결 상시 유지, 데스크톱 앱이 열려 있어야 함

정확한 가격·플랜은 3장에서 다룹니다.

macOS 설치 5단계

  1. claude.com/download에서 Claude 데스크톱 앱을 내려받아 설치합니다.
  2. 앱을 실행하고 유료 구독 계정으로 로그인합니다.
  3. 화면 상단의 모드 선택기에서 'Cowork' 탭을 찾습니다 (Chat 탭과 나란히 위치).
  4. 'Cowork' 탭을 클릭해 'Tasks' 모드로 전환합니다.
  5. 수행할 작업을 자연어로 설명하고, Claude가 제시하는 접근 방식(plan)을 검토한 뒤 실행을 허용합니다.
🖼️ 스크린샷 위치 Claude 데스크톱 앱 상단의 Chat 탭과 Cowork 탭이 나란히 보이는 화면
✓ 체크포인트 — Claude 데스크톱 앱이 설치되고 로그인되어, 상단에서 'Cowork' 탭을 클릭할 수 있는가?

Windows 설치

  • Windows는 2026년 2월 프리뷰로 도입, 4월 정식 출시(GA)에 포함되었습니다 (arm64 / x64 모두 지원).
  • claude.com/download에서 최신 버전을 설치하면, 이후 단계는 macOS와 동일합니다.

폴더 권한 — "내 전체 컴퓨터를 보는 게 아닙니다"

Claude는 사용자가 명시적으로 허용한 폴더에만 접근할 수 있습니다. 데스크톱 앱 설정에서 작업할 로컬 폴더를 연결(connect)해 접근 범위를 직접 통제합니다. 처음에는 연습용 폴더 하나만 연결하는 것을 권장합니다.

3. 가격·플랜 (유료만 가능)

Cowork는 모든 유료 플랜에 포함되며, 무료 플랜은 제외됩니다. 영구 무료 Cowork 티어는 없습니다.

Max 5x/20x는 기능 차이가 아니라 사용량 한도 배수 차이입니다. 위 수치는 2026년 6월 기준 스냅샷이며, 가격은 특히 빠르게 바뀝니다. 결제 전 claude.com/pricing에서 반드시 재확인하세요.

4. 권한·안전 모델 (꼭 알아두기)

VM 샌드박스 — 격리된 안전 공간

Cowork의 파일/폴더 작업은 격리된 가상머신(VM) 안에서 실행됩니다. 이 격리 덕분에 명시적으로 허용한 폴더 밖의 파일에는 접근하지 못합니다. 즉, Claude가 임의로 컴퓨터 전체를 헤집을 수 없습니다.

인간 승인 — 두 가지 권한 모드

모드동작권장 상황
Ask before acting (행동 전 확인)각 행동마다 멈추고 승인을 요청초보자 기본 권장
Act without asking (확인 없이 실행)멈추지 않고 빠르게 실행신뢰하는 파일·명확한 작업에만

초보자는 반드시 'Ask before acting'를 기본으로 사용하세요. Claude는 작업 전 계획(plan)을 먼저 보여주고, 사용자는 어느 단계에서든 방향을 바꾸거나(redirect) 다듬을(refine) 수 있습니다.

기본 안전 수칙

  • 삭제는 항상 별도 승인이 필요합니다. 파일을 영구 삭제하기 전 Claude는 명시적 허용("Allow")을 요청합니다.
  • 민감 폴더는 연결하지 마세요. 은행·의료·정부 관련 자료, 민감한 재무 문서가 든 폴더는 권한을 주지 않는 것이 안전합니다. (Cowork는 규제 데이터(HIPAA 등)에 대해 인증되지 않았습니다.)
  • "OK"를 습관적으로 누르지 마세요. 승인 화면이 자주 뜬다고 무심코 통과시키면(승인 피로) 안전장치가 무력해집니다. 무엇을 승인하는지 확인하세요.

Anthropic도 보호 장치가 "불완전(imperfect)"하다고 인정합니다. 자동 안전장치를 맹신하지 말고, 검증은 사용자 몫임을 기억하세요.

5. 첫 작업 따라 하기 — 폴더 문서 정리·요약 자동화

처음에는 망가져도 괜찮은 연습용 폴더로 시작합니다. 흩어진 문서 몇 개를 넣은 폴더를 만들어 두세요.

단계별 진행

  1. 바탕화면에 cowork-practice라는 연습 폴더를 만들고, 정리할 문서 파일 몇 개를 넣습니다.
  2. Claude 데스크톱 앱에서 Cowork 탭 → Tasks 모드로 들어갑니다.
  3. 설정에서 cowork-practice 폴더를 연결(권한 부여)합니다.
  4. 권한 모드가 'Ask before acting'인지 확인합니다.
  5. 작업을 자연어로 입력합니다. 예시 지시문:

    "cowork-practice 폴더의 문서들을 주제별로 분류하고, 각 문서의 핵심 내용을 1~2줄로 요약한 정리표(summary.md)를 만들어 줘. 원본 파일은 지우지 말고 그대로 둬."

  6. Claude가 제시하는 계획(plan)을 읽어보고, 이상이 없으면 실행을 허용합니다.
  7. 각 단계에서 승인 요청이 뜨면 내용을 확인한 뒤 진행합니다. 마지막에 summary.md 산출물을 확인합니다.
🖼️ 스크린샷 위치 Cowork가 작업 계획(plan)을 먼저 보여주고 사용자의 승인을 기다리는 화면
✓ 체크포인트 — 연습 폴더 안에 summary.md(또는 정리 결과 파일)가 생성되고, 원본 문서가 그대로 남아 있는가?

처음 위임할 만한 다른 작업

  • 어지러운 다운로드 폴더의 파일 이름 변경·분류·중복 정리
  • 영수증 스크린샷 모음을 경비 정산용 표로 변환
  • 회의 메모 여러 개를 모아 한 편의 보고서 초안으로 정리
