1. 바이브코딩이란?

바이브코딩(Vibe Coding)은 AI에게 자연어로 지시하여 소프트웨어를 만드는 새로운 개발 방식입니다. 코드를 직접 작성하지 않고, "이런 것을 만들어 줘"라고 말하면 AI가 코드를 생성합니다.

왜 주목받고 있을까?

기존 개발 방식바이브코딩
프로그래밍 언어 학습 필요자연어(한국어)로 지시
수백 줄의 코드를 직접 작성AI가 코드를 자동 생성
디버깅에 많은 시간 소요AI가 오류를 자동 수정
개발자만 가능누구나 시작 가능

2. Claude Code란?

터미널에서 AI와 대화하는 코딩 도구

Claude Code는 Anthropic이 만든 터미널 기반 AI 코딩 도구입니다. 마치 AI 프로그래머와 터미널에서 채팅하듯이 프로젝트를 만들 수 있어요.

"터미널"이 낯설다고요? 걱정 마세요! 터미널은 컴퓨터에게 글자로 명령을 내리는 창입니다. 마우스로 클릭하는 대신, 글을 써서 컴퓨터와 대화하는 것이라 생각하면 됩니다. (2026년부터는 터미널이 무서운 분을 위한 데스크톱 앱도 나왔어요. 4장에서 안내합니다.)

나: "포모도로 타이머 웹앱을 만들어줘"
Claude Code: (파일을 만들고, 코드를 작성하고, 실행까지 해줍니다)
나: "타이머 색상을 파란색으로 바꿔줘"
Claude Code: (해당 파일을 찾아서 수정합니다)

4. 사전 준비 — 터미널을 처음 여는 분을 위한 핸즈온

이 장은 터미널을 난생처음 여는 사람 기준으로 한 단계씩 따라 할 수 있게 썼습니다. 검은 화면이 무섭다면 한 가지만 기억하세요: 읽기만 하는 명령(pwd·ls·cd)은 절대 컴퓨터를 망가뜨리지 않습니다. 막히면 창을 닫고 새로 열면 됩니다. 진행 중인 명령이 멈추면 Ctrl + C가 탈출 버튼입니다.

필요한 것

항목설명필수 여부
Claude 계정 (Pro 이상)Claude Code는 무료 플랜으로는 쓸 수 없습니다. 최소 Pro($20/월) 필요필수
Node.jsnpm 방식으로 설치할 때만 필요 (네이티브 인스톨러는 불필요)선택
Git코드 저장 및 공유용권장
텍스트 에디터결과 확인용 (메모장도 OK)선택
중요(2026년 변경): 예전에는 npm으로 설치하는 것이 기본이었지만, 지금 Anthropic이 권장하는 1순위는 네이티브 인스톨러(명령어 한 줄)입니다. 네이티브 설치는 Node.js가 필요 없고, 백그라운드에서 자동 업데이트됩니다. npm은 "이미 Node.js를 쓰는 분용 보조 방식"으로 바뀌었습니다.

Step 1: 터미널 여는 법

🍎 Mac (맥)

  • 가장 빠른 길 — Spotlight: Command(⌘) + Space → "터미널" 또는 "terminal" 입력 → Return
  • 또는: Finder → 응용 프로그램(Applications) → 유틸리티(Utilities) → 터미널(Terminal) 더블클릭
  • 맥의 기본 셸은 zsh입니다. 별다른 설정 없이 그대로 쓰면 됩니다.
🖼️스크린샷 자리Spotlight 검색창에 "terminal"을 입력해 터미널 앱이 뜬 화면

🪟 Windows (윈도우)

윈도우는 검은 창 종류가 여러 개라 헷갈립니다. 입문자는 PowerShell 하나만 알면 충분합니다.

  • PowerShell 빠르게 열기: 시작 버튼 우클릭 → "터미널(Terminal)" 또는 "Windows PowerShell" 클릭. 또는 시작 메뉴에서 "PowerShell" 검색 → 실행.
  • Windows Terminal: Windows 11에는 기본 탑재된 "창(컨테이너)"으로, PowerShell·CMD·WSL을 탭으로 한 창에서 띄울 수 있습니다. 시작 메뉴에서 "Terminal" 검색.
  • WSL(선택): 리눅스 도구를 본격적으로 쓸 거라면 PowerShell을 관리자 권한으로 열고 wsl --install → 재부팅 → "Ubuntu" 실행. 맥/리눅스 자료를 그대로 따라 할 수 있어 장기적으로 유리하지만, "오늘 한 줄 쳐보고 싶다"면 PowerShell로 시작해도 충분합니다.
PowerShell인지 CMD인지 구분하기: 프롬프트가 PS C:\...로 시작하면 PowerShell, PS 없이 C:\...면 CMD입니다. 설치 명령이 서로 다르니 이 구분이 중요합니다.
🖼️스크린샷 자리시작 버튼 우클릭 메뉴에서 "터미널"을 선택해 PowerShell(PS C:\> 프롬프트)이 열린 화면
✓ 체크포인트 글자를 입력할 수 있는 검은(또는 짙은) 창이 떴고, 깜빡이는 커서가 보이면 성공입니다.

Step 2: 기본 명령 3개만 — 길 찾기

설치 전에 "내가 지금 어디 있는지" 확인하는 안전한 명령 3개만 연습해 봅시다. 모두 읽기 전용이라 마음껏 쳐도 됩니다.

pwd      # 지금 내가 있는 폴더 경로 보기 (Print Working Directory)
ls       # 현재 폴더 안에 무엇이 있는지 목록 보기  (Windows PowerShell도 ls 동작)
cd ~     # 홈(내 개인 폴더)으로 이동  (Change Directory)
꿀팁 — Tab 자동완성: 폴더 이름을 다 칠 필요 없습니다. cd Des까지 치고 Tab을 누르면 cd Desktop/으로 자동 완성됩니다.
✓ 체크포인트 pwd를 쳤을 때 /Users/내이름(맥) 또는 C:\Users\내이름(윈도우) 같은 경로가 나오면, 터미널과 정상적으로 대화하고 있는 것입니다.

Step 3: (선택) Node.js 설치 — npm 방식을 쓸 때만

네이티브 인스톨러(Step 4 권장 방식)를 쓰면 이 단계는 건너뛰어도 됩니다. npm 방식으로 설치하려는 분만 진행하세요.

먼저 이미 깔려 있는지 확인:

node -v    # v22.x.x 처럼 나오면 이미 설치됨 → Step 4로

command not found(맥) 또는 'node'은(는) 인식되지 않습니다(윈도우)가 나오면 미설치 상태입니다:

  1. nodejs.org 접속
  2. LTS 버전의 "Download" 버튼 클릭
  3. 다운로드한 설치 파일 실행 (Windows: .msi, Mac: .pkg) → 마법사대로 완료
  4. 터미널을 껐다 새로 연 뒤 다시 node -v로 확인 (PATH는 터미널을 새로 열 때 반영됩니다)
🖼️스크린샷 자리node -v 입력 후 v22.x.x 버전 번호가 출력된 터미널 화면

Step 4: Claude Code 설치 — 인스톨러 한 줄

아래에서 내 OS에 맞는 한 줄만 터미널에 붙여넣고 Enter를 누르세요.

🍎 Mac / Linux (권장 — 네이티브 인스톨러):

curl -fsSL https://claude.ai/install.sh | bash

🪟 Windows PowerShell (권장 — 네이티브 인스톨러):

irm https://claude.ai/install.ps1 | iex

'irm' is not recognized... 오류가 나면 지금 PowerShell이 아니라 CMD에 있는 것입니다. PowerShell을 다시 여세요.

보조 방식 — npm (이미 Node.js를 쓰는 분):

npm install -g @anthropic-ai/claude-code
  • 정확한 패키지명은 @anthropic-ai/claude-code입니다.
  • 주의: sudo npm install -g ...는 권한·보안 문제를 일으키니 쓰지 마세요.
🖼️스크린샷 자리인스톨러 한 줄을 붙여넣고 실행해 설치 진행 로그가 흐르는 터미널 화면

설치가 끝나면 확인:

claude --version    # 버전 번호가 나오면 설치 성공!
✓ 체크포인트 claude --version에서 2.x.x 같은 버전 번호가 나오면 설치 완료입니다. "명령을 찾을 수 없다"가 나오면 터미널을 껐다 새로 열고 다시 시도하세요(10장 트러블슈팅 참고).

Step 5: 인증(로그인) — claude 실행

작업할 폴더로 이동한 뒤 claude를 실행하면, 처음에는 자동으로 로그인 화면이 뜹니다.

cd ~          # 홈으로 이동 (어디서 시작해도 OK)
claude        # Claude Code 실행

  3. 별도의 API 키가 필요 없습니다. (초보자가 가장 헷갈려 하는 부분 — 구독만 있으면 됩니다.)

방법 B — API 키 입력 (종량제):

  2. 터미널에서 환경변수 설정:

🖼️스크린샷 자리브라우저에 뜬 Claude 로그인(OAuth) 승인 화면
✓ 체크포인트 로그인 후 터미널에 ✻ Welcome to Claude Code! 환영 박스와 입력 커서(>)가 나타나면, 이제 AI와 대화할 준비가 끝났습니다.

Step 6: 첫 대화 — 따라 하기

7. Claude Code 실습: 터미널에서 첫 프로젝트 만들기

이제 실제로 Claude Code를 사용해서 간단한 웹사이트를 만들어봅시다!

Step 1: 터미널 열기

  • Windows: 시작 메뉴에서 "PowerShell" 검색 → 클릭
  • Mac: Spotlight (Cmd + Space)에서 "Terminal" 검색 → 클릭
글자를 입력할 수 있는 창이 뜨면 성공!

Step 2: 프로젝트 폴더 만들고 이동하기

mkdir ~/Desktop/my-first-site    # 바탕화면에 폴더 만들기
cd ~/Desktop/my-first-site       # 그 폴더로 이동하기
mkdir = 폴더 만들기(make directory), cd = 폴더 이동(change directory)

Step 3: Claude Code 시작하기

claude

아래와 같은 환영 메시지가 나타나면 성공입니다:

╭──────────────────────────────────────────╮
│ ✻ Welcome to Claude Code!                │
│   /help for available commands           │
╰──────────────────────────────────────────╯

Step 4: AI와 대화하며 프로젝트 만들기

Claude에게 웹사이트를 만들어달라고 요청해봅시다:

> 간단한 자기소개 웹페이지를 만들어줘.
> - 이름: 김바이브 (수정 가능)
> - 직업: 바이브코딩 입문자
> - 취미: AI 도구 탐험, 독서
> - 깔끔한 디자인, 배경은 연한 파스텔 톤
> - HTML, CSS, JavaScript 파일로 만들어줘

Claude가 작업을 시작하면 이런 메시지가 나옵니다:

Claude: index.html 파일을 생성하겠습니다.
[파일 생성 내용 표시]
이 변경을 허용할까요? (y/n)
중요: Claude가 파일을 만들거나 수정할 때 y 또는 n으로 허용 여부를 묻습니다. 내용을 확인하고 y를 눌러주세요!

Step 5: 결과 확인 및 수정

파일이 만들어졌으면 바탕화면의 my-first-site 폴더에서 index.html을 더블클릭하세요. 웹 브라우저에서 내가 만든 첫 웹사이트가 나타납니다!

마음에 안 드는 부분은 계속 대화하며 수정할 수 있어요:

> 배경색을 좀 더 진한 파란색으로 바꿔줘
> 이름 아래에 "바이브코딩으로 세상을 바꾸자!"라는 슬로건을 추가해줘
> 프로필 사진 자리에 동그란 원형 placeholder를 넣어줘

수정 후 브라우저에서 새로고침(F5)하면 변경된 결과를 확인할 수 있습니다.

꿀팁: 1순위 처방은 항상 "터미널을 껐다 새로 열기"입니다. PATH는 터미널이 시작할 때 읽기 때문입니다.

11. 자주 묻는 질문 (FAQ)

Q1. Claude Code는 무료인가요?

설치 프로그램 자체는 무료지만, 사용하려면 Claude 구독(최소 Pro $20/월) 또는 API 키가 필요합니다. 무료 플랜으로는 Claude Code를 쓸 수 없습니다. API 키는 사용한 만큼만 지불합니다.

Q2. 프로그래밍을 몰라도 쓸 수 있나요?

네, 가능합니다! 한국어로 "이것 만들어줘"라고 말하면 Claude가 코드를 작성합니다. 다만 기본적인 터미널 사용법(폴더 이동, 파일 확인)은 알면 훨씬 편합니다. 이 교안에서 필요한 것은 모두 설명하니 따라해보세요.

Q3. 어떤 프로그래밍 언어를 지원하나요?

JavaScript, TypeScript, Python, Java, Go, Rust, C++ 등 거의 모든 프로그래밍 언어를 지원합니다.

Q4. Cursor와 뭐가 다른가요?

항목Claude CodeCursor
화면터미널 (글자 입력)에디터 (마우스 + 글자)
비유AI와 문자로 대화AI와 함께 문서 편집
장점자동화, 빠른 작업시각적, 직관적
추천터미널에 익숙한 분GUI를 선호하는 분
처음이라면 Cursor가 더 쉬울 수 있어요. 하지만 Claude Code는 익숙해지면 더 빠르고 강력합니다!

Q5. 만든 프로젝트는 어디에 저장되나요?

내 컴퓨터에 저장됩니다. Claude Code를 시작한 폴더에 파일이 생성되며, 인터넷이 끊겨도 파일은 그대로 남아있습니다.

Q6. 인터넷이 필요한가요?

네, AI와의 대화에는 인터넷이 필요합니다. 단, 만들어진 파일은 내 컴퓨터에 저장되므로 나중에 인터넷 없이도 볼 수 있습니다.

Q7. 한국어로 대화할 수 있나요?

네! 일상적인 한국어로 지시하면 Claude가 이해하고 작업합니다.

Q8. API 비용이 얼마나 드나요?

간단한 프로젝트 하나에 보통 $0.5~$3 정도입니다. /cost 명령어로 실시간 확인할 수 있으니 수시로 체크하세요.

항목설명

팁설명

구체적으로 요청모호한 요청은 왕복 대화가 늘어나 비용이 증가합니다
작은 단위로 작업한 번에 큰 프로젝트를 요청하지 마세요

초보자가 자주 하는 실수

실수올바른 방법
프롬프트가 너무 모호함 ("앱 만들어줘")기능, 디자인, 기술을 구체적으로 설명
폴더를 만들지 않고 시작반드시 새 폴더를 만들고 그 안에서 시작
승인 없이 무조건 y 누름어떤 파일을 변경하는지 한 번씩 확인
에러를 직접 검색Claude에게 에러 메시지를 보여주고 해결 요청
대화가 너무 길어짐/compact로 요약하거나 /clear로 새로 시작

실전 노하우

  1. 작은 것부터 시작하세요: 처음에는 간단한 웹페이지부터 만들어보세요
  2. 대화를 이어가세요: 한 번에 완벽하게 만들려 하지 말고, 조금씩 수정해나가세요
  3. 에러를 두려워하지 마세요: 에러가 나면 Claude에게 "에러가 났어. 고쳐줘"라고 하면 됩니다
  4. /cost 습관: 비용이 걱정되면 수시로 /cost를 입력해서 확인하세요
  5. 폴더 정리: 프로젝트마다 새 폴더를 만들어서 깔끔하게 관리하세요
