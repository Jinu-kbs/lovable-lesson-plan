1. 바이브코딩이란?

바이브코딩(Vibe Coding) 은 코딩을 직접 하지 않고, AI에게 일상 언어로 원하는 것을 설명하면 AI가 코드를 작성해주는 방식입니다.

  • 프로그래밍 언어를 몰라도 됩니다
  • "이런 웹사이트를 만들어줘"라고 말하면 AI가 만들어줍니다
  • 마치 디자이너에게 의뢰하듯이 대화로 진행합니다

왜 주목받고 있을까?

  • 아이디어만 있으면 누구나 웹사이트/앱을 만들 수 있습니다
  • 전문 개발자를 고용하지 않아도 프로토타입을 빠르게 만들 수 있습니다
  • 교육, 소상공인, 프리랜서, 동호회 등 다양한 분야에서 활용 가능합니다

바이브코딩 학습 경로

처음이라면 아래 순서로 단계별로 익혀가는 것을 추천합니다:

1단계: Google AI Studio 빌더 (무료, 가장 쉬움)
   ↓  "아~ 이런 거구나" 느낌 잡기
2단계: 러버블 Lovable (무료 플랜으로 체험 시작)
   ↓  본격적인 웹사이트 제작
3단계: 커서 Cursor 등 (코드 직접 제어)
   ↓  코딩에 관심이 생겼다면
실사용자 조언: "AI 스튜디오 빌더만 해봐도 '아~ 이런 거구나' 느낌을 받으시더라고요. 그 다음에 러버블로 넘어가면 훨씬 수월합니다" — 실사용자 조언

2. 러버블(Lovable)이란?

Lovable(lovable.dev)은 AI 기반 웹 앱 빌더입니다. 채팅하듯이 원하는 것을 말하면 웹사이트를 만들어줍니다.

러버블의 특징

장점설명
설치 불필요웹 브라우저만 있으면 바로 시작 가능
대화형 제작채팅하듯이 원하는 기능을 요청
즉시 미리보기만든 결과물을 실시간으로 확인 가능
원클릭 배포(Publish)호스팅·도메인까지 클릭 한 번으로 인터넷에 공개
백엔드 내장(Lovable Cloud)데이터베이스·로그인·파일 저장이 프로젝트에 기본 내장
한국어 프롬프트UI는 영어지만, 요청은 한국어로 해도 잘 동작
실전 팁: "대부분 설치하다 끝나는데, 러버블은 따로 설치할 게 없으니 신세계입니다" — 실사용자 후기

추천 영상: 러버블로 5분 만에 사이트를 만드는 과정을 직접 확인해보세요 → YouTube 보기
📱 이제 폰으로도 만들 수 있어요: 2026년 4월부터 러버블 모바일 앱(iOS·Android)이 나왔습니다. 음성이나 텍스트로 외부에서도 앱을 만들고, 빌드가 끝나면 알림을 받을 수 있습니다. (미리보기 확인은 브라우저에서 합니다.)

알아두세요: 러버블 화면은 영어입니다

러버블의 버튼과 메뉴는 영어로 되어 있지만 걱정하지 마세요:

  • 요청(프롬프트)은 한국어로 작성해도 됩니다
  • 주요 버튼만 기억하면 충분합니다:
    • New Project = 새 프로젝트 만들기
    • Plan 모드 / Build 모드 = 모드 스위처 (Plan = AI가 먼저 계획, Build = 바로 제작)
    • Preview = 미리보기
    • Publish = 바로 공개하기
    • Download = 파일 내려받기

4. 사전 준비

러버블은 웹 기반 서비스라 따로 설치할 게 없습니다. 데이터 저장·로그인 같은 백엔드도 Lovable Cloud로 프로젝트에 내장되어 있어, 예전처럼 GitHub·Vercel·Supabase에 미리 가입할 필요가 없습니다. 사실상 러버블 계정 하나만 있으면 시작할 수 있습니다.

4-1. Lovable 가입 (화면 단계별)

1) 가입 페이지 열기

  1. 브라우저에서 lovable.dev 접속
  2. 우측 상단 Sign up(또는 Get Started) 클릭
🖼️스크린샷lovable.dev 첫 화면에서 우측 상단 Sign up 버튼이 보이는 모습

2) 계정 방식 선택

  1. Continue with Google / Continue with GitHub / 이메일 중 편한 방식 선택
  2. 권한 허용 화면이 뜨면 허용(Authorize) 클릭
  3. 가입 즉시 무료 워크스페이스가 생성됩니다 (신용카드 불필요)
🖼️스크린샷로그인 방식(구글/깃허브/이메일)이 나열된 선택 화면
✓ 체크포인트 로그인 후 빈 대시보드(채팅 입력창이 있는 첫 화면)가 보이면 정상입니다.

3) (선택) 학생·교사 할인 신청

  • 학생/교사라면 lovable.dev/students에서 학교 이메일로 인증하면 Pro 플랜을 최대 50% 할인받을 수 있습니다. (적용 조건·할인율은 공식 페이지에서 재확인하세요.)

사전 준비 체크리스트

  • Lovable 계정 생성 완료 (무료 워크스페이스 확인)
  • (해당 시) 학생·교사 할인 신청
  • 만들고 싶은 웹사이트 아이디어 1개 이상 구상
  • (선택) GitHub·Vercel 계정 — 나만의 코드 보관/외부 호스팅을 원할 때만

5. 아이디어 구상하기

러버블에 바로 뛰어들기 전에, 무엇을 만들 것인지 먼저 정리하는 것이 중요합니다.

시작 미션 3가지

무엇을 만들지 아직 정하지 못했다면, 아래 미션을 따라해보세요:

  1. 기획 대화하기: 제미나이/ChatGPT에게 하고 싶은 것을 이야기하며 기획하기 (기획 도우미 Gem 활용)
  2. 아이디어 10개 뽑기: 하고 싶은 게 없다면 AI에게 "24시간 동안 할 수 있는 프로젝트 10개를 추천해줘"라고 요청하기
  3. 디자인 참고 수집: 다른 앱이나 사이트를 둘러보며 마음에 드는 디자인을 캡처해두기
추천 첫 프로젝트: 뭘 만들지 모르겠다면 개인 포트폴리오 웹사이트부터 시작해보세요! 가장 간단하면서도 완성감이 있습니다.

6. PRD(요구정의서) 만들기

PRD란?

PRD 는 "내가 만들 것을 정리한 기획서"입니다. 러버블에 입력하기 전에 PRD를 만들어두면 훨씬 좋은 결과물을 얻을 수 있습니다.

실전 팁: "그냥 막 던지면 코드 수정이 어렵거나 돌아올 수 없는 강을 건너기도 해요" — 실사용자 조언

"만들고 있던 앱의 명세서를 넣고 한 번 하니까 크레딧이 끝났어요" — 실사용자 경험

왜 PRD가 필요할까?

  • 없이 시작하면: 크레딧 낭비 + 결과물 뒤죽박죽 + 수정에 수정 반복
  • 있으면: 한 번에 원하는 결과에 가까운 결과물 + 크레딧 절약

간단한 PRD 작성법

AI에게 아래와 같이 요청하세요:

아까 정리한 [프로젝트 이름]에 대해
PRD(요구정의서)를 작성해줘.

아래 항목을 포함해줘:
1. 프로젝트 이름
2. 프로젝트 목적
3. 누가 사용하나?
4. 어떤 기능이 필요한가?
5. 어떤 페이지가 필요한가?
6. 디자인 느낌 (색상, 분위기)
PRD 예시 보기 (카페 소개 사이트) 
# PRD: 해피빈 카페 소개 사이트

## 프로젝트 목적
카페를 방문하려는 손님에게 필요한 정보를 한눈에 제공

## 대상 사용자
- 카페를 찾는 손님
- 카페 사장님 (관리자)

## 핵심 기능
1. 카페 소개 (스토리, 분위기 사진)
2. 메뉴판 (음료/디저트, 가격)
3. 영업시간 및 위치
4. 인스타그램/네이버 지도 링크

## 페이지 구성
- 홈: 카페 대표 이미지 + 한 줄 소개
- 메뉴: 음료/디저트 목록
- 오시는 길: 주소, 영업시간, 지도
- 소개: 카페 이야기

## 디자인 요구사항
- 따뜻하고 아늑한 느낌 (베이지, 브라운 톤)
- 사진이 돋보이는 레이아웃
- 스마트폰에서도 잘 보이게

크레딧이 줄어드는 방식 (꼭 알아두기)

  • 옛날처럼 "1요청 = 1크레딧"이 아니라, 작업 복잡도에 따라 차등 소모됩니다.
    • Plan 모드 메시지: 1크레딧(고정)
    • Build 모드: 버튼 색 바꾸기 약 0.5 / 로그인 추가 약 1.2 / 이미지 포함 랜딩페이지 약 2.0크레딧
  • 크레딧은 빌드(만들 때) + Cloud 호스팅·실행 + 배포된 앱의 AI 기능이 하나로 합쳐진 통합 잔액입니다.
⚠️ 운영 중에도 크레딧이 빠집니다: 크레딧은 "만들 때만" 쓰는 게 아닙니다. 공개한 앱이 실제로 돌아가며 쓰는 호스팅·데이터·AI 사용량도 통합 크레딧에서 빠져나갑니다. 방문자가 늘면 예상보다 비용이 커질 수 있다는 점을 기억하세요.
📌 과거 안내: 이 교안은 원래 2026년 3월 "She Builds on Lovable" 이벤트(무료 25시간 무제한 빌드, $100 Claude API·$250 Stripe 크레딧)를 계기로 작성됐습니다. 그 이벤트성 혜택은 지금은 종료되었으니, 현재는 위의 일반 무료 플랜·크레딧 기준으로 학습하세요.

  2. 대시보드의 채팅 입력창에 만들고 싶은 것을 한국어로 입력하면 바로 첫 프로젝트가 시작됩니다
  3. (또는 별도 New Project 버튼으로 빈 프로젝트를 먼저 만들 수도 있습니다)
🖼️스크린샷대시보드 가운데 큰 채팅 입력창과 "무엇을 만들고 싶나요?" 안내가 보이는 화면
✓ 체크포인트 채팅 입력창에 글을 쓰고 보내면, 오른쪽에 미리보기가 준비되는 화면으로 넘어가면 정상입니다.

Step 2: Plan 모드 / Build 모드 고르기 (매우 중요!)

반드시 기억하세요: 입력창 근처의 Plan 모드 / Build 모드 스위처를 확인하세요!

Plan 모드: AI가 바로 만들지 않고 먼저 계획·질문·정리를 합니다. 처음 큰 구조를 잡을 때 추천. 메시지당 1크레딧 고정.
Build 모드: 바로 코드를 생성합니다. 작업 복잡도에 따라 약 0.5~2.0크레딧.

예전 교안의 "Chat 버튼 켜기"가 지금은 이 Plan 모드로 바뀌었습니다. 처음에는 Plan 모드로 구조를 잡고, 세부 수정은 Build 모드로 진행하면 결과가 더 좋습니다.
🖼️스크린샷채팅 입력창 옆/위에 Plan · Build 모드를 전환하는 토글(스위처)이 보이는 모습
✓ 체크포인트 Plan / Build 라벨이 보이고 서로 전환되면 정상입니다.

Step 4: 결과 확인 및 수정

  1. 러버블이 코드를 생성하면 미리보기(Preview) 에서 결과를 확인합니다
  2. 미리보기 위쪽 툴바에서 화면을 직접 손볼 수 있습니다. 현재는 4가지 모드로 나뉩니다:
    • Select: 요소 고르기
    • Edit text: 글자 직접 수정
    • Draw annotation: 화면 위에 주석(동그라미 등) 그리기
    • Add comment: 코멘트 남기기
  3. AI 기반 Visual Edits: 디자인 편집이 AI로 동작합니다. 정적인 부분뿐 아니라 데이터베이스/API에서 오는 동적 콘텐츠까지 편집할 수 있고, 일일 한도 내에서는 무료입니다.
  4. 마음에 들지 않는 부분이 있으면 대화로 수정 요청합니다
🖼️스크린샷미리보기 위쪽에 Select / Edit text / Draw annotation / Add comment 4개 모드 버튼이 있는 툴바
✓ 체크포인트 미리보기에서 요소를 클릭해 고르거나 글자를 직접 고칠 수 있으면 정상입니다.

Step 5: 데이터 저장·로그인이 필요하면 (Lovable Cloud)

게시판처럼 데이터를 저장하거나 로그인 기능이 필요하면, 예전처럼 Supabase에 따로 가입할 필요가 없습니다. 채팅으로 그냥 요청하면 됩니다.

  1. 채팅에 그대로 요청합니다

  2. 러버블이 Lovable Cloud(내장 백엔드)를 자동으로 켭니다 — 데이터베이스·로그인·파일 저장이 바로 생깁니다
  3. 리전(지역) 선택: 처음 켤 때 Americas / Europe / Asia Pacific 중 고릅니다. 한국 사용자는 Asia Pacific 권장(한 번 정하면 바꿀 수 없습니다)
🖼️스크린샷채팅에 DB·로그인 추가를 요청했을 때 Lovable Cloud 활성화/리전 선택 안내가 뜬 화면
✓ 체크포인트 채팅 사이드에 "Cloud" 또는 데이터베이스 관련 탭/표시가 생기면 정상입니다. (정적인 소개 사이트만 만든다면 이 단계는 건너뛰어도 됩니다.)

8. 웹사이트 공개하기 (배포)

기본: 러버블 Publish 한 번이면 끝 (대부분 이걸로 충분)

이제 GitHub·Vercel을 거치지 않아도 됩니다. 호스팅·CDN·도메인이 러버블에 모두 내장되어 있어서 Publish 버튼 한 번이면 공개됩니다.

  1. 프로젝트 우상단 Publish 버튼 클릭
  2. 잠시 후 프로젝트이름.lovable.app 형태의 URL이 자동 생성됩니다
  3. 그 URL을 공유하면 끝!
🖼️스크린샷우상단 Publish 버튼과, 클릭 후 생성된 *.lovable.app 공개 URL이 표시된 화면
✓ 체크포인트 새 탭에서 그 URL을 열었을 때 내가 만든 사이트가 그대로 보이면 배포 성공입니다.
팁: 수정한 내용이 아직 공개에 반영되지 않았으면 Publish 버튼에 표시(인디케이터)가 뜹니다. 다시 Publish를 누르면 최신 내용으로 갱신됩니다. 커스텀 도메인 연결도 러버블 안에서 처리할 수 있습니다.

선택(고급): GitHub + Vercel 등 외부 호스팅

코드를 직접 보관하거나 외부 인프라로 옮기고 싶은 경우에만 사용하는 선택 경로입니다. 처음 학습 단계에서는 필요하지 않습니다.

  1. 러버블 프로젝트에서 GitHub 연동으로 코드를 저장소에 올립니다
  2. vercel.com 등에서 그 저장소를 Import → Deploy 합니다
  3. (Git을 모르면, 러버블에서 Download로 ZIP을 받아 GitHub에 직접 업로드하는 방법도 있습니다)
대부분의 초보자는 위 "기본: Publish"만으로 충분합니다. 외부 호스팅은 나중에 필요할 때 시도하세요.

"러버블이 이상한 결과를 만들었어요"
  1. 당황하지 마세요 — 러버블에는 되돌리기(Undo) 기능이 있습니다
  2. 이전 버전으로 돌아가서 다시 시도하세요
  3. 마음에 드는 상태에서 미리 파일을 다운로드해두면 안전합니다
"배포(Publish)가 안 돼요 / 사이트가 안 보여요"
  • 먼저 Publish 버튼을 다시 눌러 최신 내용으로 갱신했는지 확인하세요 (미반영 표시가 떠 있으면 재배포)

  • 빌드 에러가 있으면 채팅으로 "에러를 고쳐줘"라고 요청하면 됩니다
"(선택) GitHub/Vercel 연동이 안 돼요"
  • 이 경로는 외부 호스팅을 원할 때만 쓰는 선택 사항입니다 — 기본은 러버블 Publish로 충분합니다
  • GitHub 연동 권한을 Lovable 설정에서 허용했는지 확인하세요
  • 그래도 안 되면 러버블에서 Download(ZIP) 후 GitHub에 직접 업로드하세요
"카카오톡에 공유했는데 썸네일이 안 나와요"
  • 카카오톡은 한번 읽어간 썸네일(OG 이미지)을 캐시합니다
  • 사이트를 수정해도 카톡 미리보기가 바로 바뀌지 않습니다
  • 해결 방법: 카카오 OG 캐시 초기화 페이지에서 URL을 입력하고 "캐시 초기화" 버튼을 누르세요
  • OG 이미지가 아예 없다면 러버블 프로젝트에 "OG 메타 태그와 썸네일 이미지를 추가해줘"라고 요청하세요

Q1. Plan 모드와 Build 모드 중, 메시지당 크레딧이 1로 고정된 모드는 무엇인가요?

정답: Plan 모드입니다. Plan 모드는 AI가 먼저 계획·질문·정리를 하며 메시지당 1크레딧 고정입니다. 반면 Build 모드는 작업 복잡도에 따라 약 0.5~2.0크레딧이 차등 소모됩니다.

Q2. 러버블에서 별도 가입 없이 데이터베이스·로그인·파일 저장을 제공하는 내장 백엔드의 이름은 무엇인가요?

정답: Lovable Cloud입니다. 채팅으로 "데이터베이스/로그인 추가해줘"라고 요청하면 자동으로 켜지며, 예전처럼 Supabase에 따로 가입하지 않아도 됩니다.

Q3. 만든 웹사이트를 호스팅·도메인까지 클릭 한 번으로 공개할 때 누르는 버튼의 이름은 무엇인가요?

정답: Publish 버튼입니다. 누르면 잠시 후 프로젝트이름.lovable.app 형태의 공개 URL이 자동 생성되고, 그 URL을 공유하면 끝입니다.

11. 자주 묻는 질문 (FAQ)

Q: 무료 계정이면 얼마나 쓸 수 있나요?

무료(Free) 플랜은 하루 빌드 5개(월 최대 30개) 와 약간의 Cloud·AI 크레딧이 주어집니다. 작업 복잡도에 따라 크레딧이 차등 소모되니(약 0.5~2.0), 체험·소규모 데모에는 충분하지만 본격 제품 출시에는 부족합니다. 더 쓰려면 Pro($25~) 플랜으로 올리고, 학생·교사는 50% 할인을 받으세요. (수치는 공식 가격 페이지에서 재확인하세요.)

Q: 러버블에 자체 데이터베이스가 있나요?

네, 이제 있습니다! Lovable Cloud가 프로젝트에 기본 내장되어, 채팅으로 "데이터베이스/로그인 추가해줘"라고 하면 데이터베이스·인증·파일 저장이 자동으로 생깁니다. 예전처럼 Supabase에 따로 가입하지 않아도 됩니다. (독립적인 Supabase 프로젝트가 꼭 필요한 고급 사용자는 직접 연결하는 별도 경로도 있습니다.)

Q: 프롬프트를 한국어로 써도 되나요?

네! 러버블의 화면(UI)은 영어이지만, 프롬프트(요청)는 한국어로 작성해도 잘 동작합니다. 만들어지는 웹사이트 내용도 한국어로 생성됩니다.

Q: 무료 플랜으로 바로 시작해도 되나요?

네! 무료 플랜으로 바로 체험을 시작할 수 있습니다. 다만 하루 빌드 5개 제한이 있으니, 아이디어와 PRD를 미리 준비해 한 번에 정확히 요청하면 크레딧을 아낄 수 있습니다.

Q: 만든 사이트를 나중에 수정할 수 있나요?

네! 러버블에서 언제든 수정 가능하고, (선택적으로) GitHub에 올린 코드는 다른 도구(커서, VS Code 등)에서도 수정할 수 있습니다.

Q: 꼭 GitHub과 Vercel을 써야 하나요?

아니요. 이제 러버블 Publish 버튼 한 번이면 호스팅·도메인까지 내장 처리되어 공개됩니다. GitHub + Vercel은 코드를 직접 보관하거나 외부 인프라로 옮기고 싶을 때만 쓰는 선택 사항입니다.

Q: 처음이라 아무것도 못 만들 것 같은데, 어떤 도구부터 시작하면 좋을까요?

바이브코딩 자체가 처음이라면 AI Studio 빌더부터 시작하는 것도 좋습니다. 설치 없이 '아~ 이런 거구나' 느낌을 받을 수 있어요. 그 다음에 러버블로 넘어오면 훨씬 수월합니다. "휘둘리지 않으셔도 돼요. 하나에 익숙해지는 게 중요합니다" — 실사용자 조언

Q: 러버블은 어떤 AI를 쓰나요?

빌드(코드 생성)의 핵심 모델은 Claude Opus 4.7(Anthropic)입니다. 이미지 생성은 GPT Image 2, Nano Banana 2(Gemini) 등에서 선택할 수 있습니다. 요청은 한국어로 해도 잘 동작합니다.

Q: 디자인 색상을 직접 바꿀 수 있나요?

네! 러버블에는 AI 기반 Visual Edits가 있어서 색상·텍스트·레이아웃을 직접 수정할 수 있습니다. 미리보기 위 툴바의 Select / Edit text / Draw annotation / Add comment 4모드로 요소를 고르고, 글자를 고치고, 주석·코멘트를 남길 수 있습니다. 정적인 부분뿐 아니라 데이터에서 오는 동적 콘텐츠까지 편집되고, 일일 한도 내에서는 무료입니다.

Q: 러버블로 만든 후 구조를 몰라도 괜찮을까요?

처음에는 괜찮지만, 프로젝트가 커지면 구조를 이해하지 못하면 수정이 어렵고 크레딧도 많이 소모됩니다. 그래서 이 교안에서 PRD(기획서)를 먼저 작성하는 것을 강조하는 것입니다. 기본적인 구조를 이해하면서 진행하면 나중에 훨씬 수월합니다.

자주 하는 실수

  1. 기획 없이 바로 시작하기
    • PRD를 먼저 만들어서 한 번에 정확하게 요청하세요
  2. 너무 큰 프로젝트를 한 번에 요청하기
    • 작은 단위로 나누어서 요청하세요
    • 예: "전체 쇼핑몰" 대신 "메인 페이지" → "상품 목록" → "연락처" 순서로
  3. 수정 방향을 모호하게 요청하기
    • "좀 더 이쁘게" 대신 "배경을 연한 노란색으로, 글자를 더 크게"
  4. 백업 없이 큰 수정 요청하기
    • 마음에 드는 상태에서 꼭 파일을 다운로드해두세요

실전 노하우 모음

  • 큰 구조를 잡을 때는 Plan 모드 를 쓰세요 — AI가 먼저 계획한 후 만듭니다
  • 사전에 다른 AI(ChatGPT, 제미나이 등)에서 아이디어를 정리해두면 불필요한 왕복을 줄일 수 있습니다
  • 마음에 드는 결과물은 바로 파일 다운로드 해두세요
  • 러버블은 빌드에 Claude Opus 4.7(Anthropic) 모델을 사용합니다 — 무료 플랜으로 체험해보세요
  • 내 생각을 넣지 마세요: AI에게 "다른 작업들 추천해보세요. 전체적으로 검증해보고"라고 요청하면 놓친 부분을 찾아줍니다
  • 어느 정도 만들었다면 "현재까지 프로세스를 확인하고, 개선사항을 리포트해줘" 라고 요청해보세요. 신세계를 경험하게 됩니다
