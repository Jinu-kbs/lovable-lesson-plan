4

가격·과금 동향 + 비용 리터러시

2026년 업계 전체가 사용량 기반(usage-based) 과금으로 이동했습니다. Copilot·Cursor·Codex·Claude Code가 12개월 안에 모두 이동했고, "한 번의 에이전트 실행이 구독료를 초과"하는 일이 흔해졌습니다.

  • "월 정액 = 무제한"이 아니라 "월 정액 = 일정 한도 + 초과 시 종량(API rate) 과금"이 현실입니다.
  • 예: Claude Code 실비용은 벤더 엔지니어링 문서 기준 개발자당 월 $150~250 수치가 반복 인용됩니다("$20 Pro 구독" 헤드라인과의 간극에 주의).
  • 크레딧은 보통 이월되지 않습니다(no rollover). 정책·한도·가격은 월 단위로 바뀝니다 — 게시 시점 공식 페이지 재확인 필수.

비용 리터러시 박스 — "월 $20 무제한" 환상 경고

"월 $20 무제한" 환상을 버리세요. 토큰 수학으로 보면 실제 월 지출은 사용량에 따라 $20에서 $1,000+까지 벌어집니다. 비용을 "이해하고 통제하는 것"이 새로운 필수 역량입니다.

5

AI 에이전트 기능

2026년 상반기 가장 큰 변화는 "에이전트가 도구의 부가기능에서 1차 인터페이스로 승격"된 것입니다. 핵심은 "에이전트에게 일을 시키고 → 감독하고 → 검증하는" 능력입니다.

5.1 자율성은 스펙트럼 — 5단계

에이전트성은 켜고 끄는 스위치가 아니라 연속적인 스펙트럼입니다. 높은 자율성이 항상 좋은 것은 아닙니다 — 자율성이 높아질수록 검증 부담이 커지고, 잘못된 방향으로 멀리 가버릴 위험이 커집니다.

L1 도구·어시스트
사람이 운전, AI는 보조 · 예: 자동완성, 채팅 Q&A
L2 협업(코파일럿)
사람과 AI가 번갈아 · 예: IDE 인라인 편집
L3 컨설턴트형 ← 초보자 권장
AI가 초안·계획, 사람이 검토 · 예: "계획 모드" → 승인 후 실행
L4 승인 기반 자율
AI가 실행, 사람은 위험한 지점만 승인 · 예: 터미널 명령 직전 승인
L5 완전 자율
AI가 트리거·실행·완료까지 · 예: 백그라운드/클라우드 에이전트

5.3 멀티에이전트 오케스트레이션

여러 에이전트를 함께 쓸 때 프로덕션에서 지배적인 세 가지 구조:

🗂️ 슈퍼바이저/계층형

조율자가 워커를 지휘하는 트리 구조.

중앙 지휘

🎯 오케스트레이터-워커

가장 흔한 형태(프로덕션의 약 70%, 단일 출처 — 방향성). 작업을 분해해 특화 워커에 라우팅 후 결과를 합칩니다.

분해→라우팅→통합

🐝 스웜(swarm)

중앙 통제 없는 동료 에이전트들(예: Claude Code "에이전트 팀").

팀원끼리 직접 통신

비용의 냉정한 진실

멀티에이전트는 공짜가 아닙니다. 독립형은 약 58%, 중앙집중형은 약 285% 추가 토큰 오버헤드가 보고됩니다(방향성). 에이전트 N개를 돌리면 토큰을 N배 빨리 씁니다. 단순 작업은 단일 세션이 정답입니다.

5.4 에이전틱 감독 3단계 루프

수준과 무관하게 학습자의 "감독 루프"는 동일한 형태를 띱니다.

1

시키기 (Delegate)

명확한 의도·제약·완료 조건을 프롬프트로 전달

→
2

실패 디버깅 (Debug)

에러를 읽고 맥락과 함께 AI에 재요청

→
3

결과 검증 (Verify)

동작 확인 + 정말 의도대로인지 점검

↺ 통과 못 하면 다시 ①로 — 통과할 때까지 루프를 돕니다.

위임 기준 = 검증 가능성 × 위험도

"맞는지 쉽게 냄새만 맡아봐도 되는(sniff-check)" 저위험·검증 쉬운 작업부터 AI에 맡기세요. 동작만 보고 그냥 수용(vibe 수용)하는 습관이 굳으면 보안·품질 사고로 이어집니다.

5.5 HITL 안전 5계명

자율성이 높아질수록 안전·감독이 비례해 중요해집니다.

① HITL (인간 승인 루프)
위험한 행동(터미널·파일 쓰기·결제) 직전에만 승인을 요구하고, 안전한 읽기는 자율로(최소 권한).
② 자동화 편향 경계
믿을 만해 보일수록 감시가 느슨해집니다. 검증이 사람 몫임을 잊지 마세요.
③ 권한·샌드박스
쓰기 권한이 필요 없으면 주지 않고, 프로덕션 데이터가 필요 없으면 샌드박스에서.
④ 메모리로 망각 다스리기
에이전트는 건망증이 심합니다. CLAUDE.md/AGENTS.md에 규칙을 적어 매 세션 자동 주입.
⑤ 비용으로 욕심 다스리기
멀티/백그라운드 에이전트는 토큰을 빠르게 소모합니다. "공짜 병렬화"가 아닙니다.

6.2 EU AI Act — 교육이 고위험 직접 대상

2026년 8월 발효 임박 (EU 한정 · 한국은 참고)

EU AI Act 고위험·투명성 의무가 발효 임박입니다. 교육은 ① 고위험 응용 ② 취약계층 보호가 겹치는 영역으로 특별 취급되어 학교·대학·EdTech가 직접 규제 대상입니다. 이는 EU 한정이며 한국 사이트 맥락에서는 "참고" 정보이나, 한국도 학운위 심의·개인정보보호 등 가드레일 강화 흐름은 동일합니다.
