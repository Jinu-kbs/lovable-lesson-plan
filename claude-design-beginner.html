1. Claude Design이란?

학습 목표

  • Claude Design이 무엇을 만드는 도구인지 이해한다
  • Figma·Lovable과 어떻게 다른지 한 문장으로 설명할 수 있다

한 줄 정의

Claude Design은 자연어 프롬프트로 디자인·프로토타입·슬라이드·원페이저 같은 시각 결과물을 Claude와 함께 만드는 협업 도구입니다. Anthropic의 실험 제품 브랜드인 Anthropic Labs에서 내놓았고, 엔진은 Anthropic이 "가장 강력한 비전(vision) 모델"이라 부르는 Claude Opus 4.7입니다. 공식 태그라인은 "Your idea, designed with Claude(당신의 아이디어, Claude와 함께 디자인하다)"입니다.

핵심은 "디자인 전문 도구"라기보다 아이디어를 시각·인터랙티브 결과물로 바꿔주는 협업 캔버스라는 점입니다.

무엇을 넣고, 무엇이 나오나

Claude Design은 다양한 입력을 받아 완성도 높은 결과물을 만들어 줍니다.

입력(넣는 것)출력(나오는 것)
텍스트 프롬프트 (자연어 설명)인터랙티브 프로토타입
참고 이미지·스크린샷와이어프레임·목업
문서 (DOCX·PPTX·XLSX)피치덱·프레젠테이션 슬라이드
코드베이스(연결된 저장소)랜딩 페이지·마케팅 자산
웹 캡처(기존 사이트 요소)이력서·원페이저 같은 문서

Figma·Lovable과 뭐가 다른가

  • Figma처럼 픽셀을 일일이 그리는 전문가 도구가 아닙니다.
  • Lovable처럼 곧장 풀스택 앱을 배포하는 도구도 아닙니다.
  • 그 둘 사이, "백지에서 시작해 빠르게 보여줄 무언가를 만드는" 속도 영역을 차지합니다.

결과물의 품질은 "프로덕션 그대로 쓸 디자인"이 아니라 "의사소통하기에 충분한 품질"입니다. 즉 디자이너를 대체하는 게 아니라, 비(非)디자이너(교사·PM·창업자·마케터)가 디자이너를 부르기 전에 빠르게 시각화하는 도구입니다.

"Figma를 못 다뤄도 머릿속 화면을 30분 만에 보여줄 수 있게 됐다" — 실사용자 후기

3. 첫 프로토타입 만들기 (따라하기)

학습 목표

  • 프롬프트 한 줄로 첫 결과물(랜딩 페이지)을 생성할 수 있다
  • 생성 화면(협업 캔버스)의 흐름을 이해한다

단계별 따라하기

1단계 — 진입

브라우저에서 claude.ai/design에 접속하고 로그인합니다. (Pro 이상 구독 필요)

▢ 스크린샷 자리 claude.ai/design 첫 화면 — 프롬프트 입력창

2단계 — 프롬프트 입력

화면 중앙 입력창에 만들고 싶은 것을 자연어로 설명합니다. 처음에는 한 문장이면 충분합니다.

교사 연수 안내 랜딩 페이지를 만들어줘.
따뜻한 톤, 상단에 큰 제목, 가운데 일정 안내, 맨 아래 신청 버튼 포함.

팁: "무엇을(랜딩 페이지) + 어떤 느낌으로(따뜻한 톤) + 어떤 요소가 들어가야 하는지(제목·일정·신청 버튼)"를 적으면 결과가 훨씬 좋아집니다.

3단계 — 생성 기다리기

Claude가 협업 캔버스(collaborative canvas)에 초안(draft)을 그립니다. 잠시 기다리면 화면에 실제로 클릭되는 프로토타입이 나타납니다.

▢ 스크린샷 자리 캔버스에 생성된 랜딩 페이지 초안
체크포인트
  • ✅ claude.ai/design에 접속해 로그인했는가?
  • ✅ 프롬프트를 한 문장 입력했는가?
  • ✅ 캔버스에 랜딩 페이지 초안이 나타났는가?

여기까지 됐다면 여러분은 방금 코드 한 줄 없이 첫 프로토타입을 만들었습니다.

4. 기본 편집

학습 목표

  • 생성된 결과물을 세 가지 방법으로 다듬을 수 있다

다듬기 3종

Claude Design은 초안을 다듬는 세 가지 쉬운 방법을 제공합니다.

방법어떻게언제 쓰나
인라인 코멘트특정 요소를 콕 집어 코멘트를 남김"이 버튼 색을 초록으로" 같이 부분 수정
직접 텍스트 편집텍스트를 클릭해 바로 수정제목·문구 오타 고치기
조정 슬라이더간격(spacing)·색상(color)·레이아웃을 실시간 미세 조정전체 톤·여백 다듬기

따라하기

▢ 스크린샷 자리 인라인 코멘트로 버튼 색 바꾸기
  1. 바꾸고 싶은 요소(예: 신청 버튼)를 클릭합니다.
  2. 인라인 코멘트로 "신청 버튼을 더 크고 눈에 띄는 색으로 바꿔줘"라고 입력합니다.
  3. 제목 텍스트를 직접 클릭해 문구를 고쳐 봅니다.
  4. 조정 슬라이더로 요소 사이 간격을 살짝 넓혀 봅니다.
체크포인트
  • ✅ 인라인 코멘트로 요소 하나를 수정했는가?
  • ✅ 텍스트를 직접 편집해 봤는가?
  • ✅ 조정 슬라이더로 간격이나 색을 바꿔 봤는가?

5. 결과물 내보내기

학습 목표

  • 만든 결과물을 어떤 형식으로 내보낼 수 있는지 안다

만든 결과물은 용도에 맞게 여러 형식으로 내보낼 수 있습니다.

내보내기용도
PDF문서 제출·인쇄
PPTX (PowerPoint)발표 슬라이드
HTML (단독 파일)정적 웹페이지·랜딩 페이지로 바로
Canva 연동Canva에서 후속 디자인 편집

공유도 가능합니다. 조직 범위(organization-scoped)로 비공개(private)·보기 전용(view-only)·편집(edit) 권한을 정해 내부 URL로 팀에 전달할 수 있습니다.

6. 토큰 절약 주의

학습 목표

  • Claude Design이 사용량(토큰)을 많이 쓸 수 있음을 알고 절약 습관을 익힌다

Claude Design은 결과물을 만들 때 사용량(토큰)을 꽤 많이 소모합니다. 출시 초기에는 한 리뷰어가 프로토타입 변형을 만들다가 약 25분 만에 주간 한도의 80%를 소진했다는 보도가 여러 매체에 인용될 정도였습니다. (2026년 6월 업데이트로 토큰 효율이 개선되고 채팅·Claude Code 등과 사용 한도를 공유하도록 바뀌었지만, 여전히 절약 습관이 필요합니다.)

절약 팁

  • 초기 반복은 가볍게: 구조를 잡는 초기 단계에서는 간단한 와이어프레임 수준으로 빠르게 반복하세요.
  • 정교한 작업은 나중에: 큰 구조가 잡힌 뒤에만 정교한 목업·디테일을 만드세요.
  • 프롬프트를 명확하게: 한 번에 의도를 분명히 적을수록 재생성 횟수가 줄어 토큰을 아낍니다.

"와이어프레임으로 먼저 흐름만 잡고, 마음에 들 때만 예쁘게 다듬으니 한도가 훨씬 오래 갔다" — 실사용자 조언

🧠 이해했는지 확인해 보세요

아래 질문에 스스로 답한 뒤, 펼쳐서 정답을 확인하세요.

Q1. Claude Design 결과물이 목표로 하는 품질 수준은?

정답: "프로덕션에 그대로 쓸 디자인"이 아니라 "의사소통하기에 충분한 품질"입니다. 디자이너를 대체하는 게 아니라, 비디자이너가 디자이너를 부르기 전에 빠르게 시각화하는 도구입니다.

Q2. 생성된 초안을 다듬는 편집 3종은 무엇인가?

정답: ① 인라인 코멘트(요소를 콕 집어 수정), ② 직접 텍스트 편집(클릭해 바로 수정), ③ 조정 슬라이더(간격·색상·레이아웃 실시간 미세 조정).

Q3. 토큰(사용량)을 아끼려면 초기 단계에서 어떻게 작업하는 게 좋은가?

정답: 초기 반복은 간단한 와이어프레임 수준으로 가볍게 하고, 큰 구조가 잡힌 뒤에만 정교한 목업·디테일을 만듭니다. 프롬프트를 명확히 적어 재생성 횟수를 줄이는 것도 토큰 절약에 도움이 됩니다.
